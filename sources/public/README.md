# Approved redistributable source copies

Track a copy here only when its redistribution status is `approved`.

Every copy needs a matching record under `sources/metadata/` giving title,
authors, venue, date, stable URL or DOI, retrieval date, hash, licence, and
the basis for the redistribution decision.

Never place restricted, licensed, private, unknown, or not-approved material
here. Never copy `../osr-claude/sources/restricted-microsoft/` into this
directory or any tracked artifact.
