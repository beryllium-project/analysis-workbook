# Quarantined source copies

Restricted, licensed, private, unknown, and not-approved copies are held here.
All contents other than this policy file are ignored by Git.

A quarantined copy may be read as evidence and cited through a
`source://quarantine/...` logical locator, but its text must not be reproduced
in a tracked artifact beyond what the analysis genuinely requires and the
licence permits.

Never copy `../osr-claude/sources/restricted-microsoft/` here or anywhere else
in this repository.
