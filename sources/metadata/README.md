# Source metadata

Citations, hashes, retrieval records, query records, and acquisition results
are tracked here regardless of whether a copy of the source may be stored.

A metadata record must state title, authors, venue, date, stable URL or DOI,
retrieval or checked date, sensitivity (`public`, `internal`, `private`, or
`restricted`), and redistribution status (`approved`, `not-approved`,
`unknown`, or `not-applicable`).

Metadata never contains restricted source text, credentials, or absolute
workstation paths.
